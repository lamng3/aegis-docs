What it is

An agent that answers questions over a knowledge graph reads the graph through an ontology. The ontology says which classes a query term covers and which links may be followed, so editing a few ontology triples changes the answers while every fact in the graph stays intact. Aegis studies that threat from both sides.

  • Attack. Given a query workload and a budget of k edits, find the chain that lowers answer quality most. Aegis searches the tree of edit chains with greedy, beam, random, and UCT (a bandit at every node).
  • Protection. Given room to lock M triples, choose the locks that leave the attacker's best response least harmful.
  • Recovery. Every edit is a logged transaction with its undo. Aegis measures what each edit changed, detects the first harmful commit, and rolls back while keeping honest edits.
